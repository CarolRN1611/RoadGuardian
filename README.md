# RoadGuardian

## Descrição

RoadGuardian é um site estático para uma empresa de rastreamento de mercadorias. O projeto apresenta informações sobre os serviços oferecidos, funcionalidades, benefícios e formas de contato.

## Funcionalidades

- **Página Inicial**: Carrossel com vídeos promocionais e chamadas para ação.
- **Sobre Nós**: Informações sobre a empresa.
- **Funcionalidades**: Destaque das principais características do serviço.
- **Benefícios**: Vantagens de usar o RoadGuardian.
- **Contato**: Formulário de contato e links para redes sociais.

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilização personalizada.
- **Bootstrap 5**: Framework para layout responsivo.
- **Font Awesome**: Ícones.
- **JavaScript**: Funcionalidades interativas (carrossel, navegação).

## Instalação e Uso

1. Clone o repositório:
   ```
   git clone https://github.com/seu-usuario/RoadGuardian.git
   ```

2. Navegue até o diretório do projeto:
   ```
   cd RoadGuardian
   ```

3. Abra o arquivo `index.html` em um navegador web.

Não há dependências externas além das bibliotecas CDN incluídas no HTML.

## Estrutura do Projeto
